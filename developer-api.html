VidSynth AI Developer API

Programmatic access to the VidSynth AI Generation Pipeline, character transformation conditioning, reference image ingestion, and asynchronous batch visual processing. All endpoints require an approved organization API token.

Request Developer Access → Partner engineering contact: founder@vidsynth.app
01 // API DOCUMENTATION REST JSON v1

Architecture & Base URI

The VidSynth AI API is organized around RESTful JSON workflows with deterministic idempotency keys (`X-VidSynth-Request-Id`) and signed asset delivery URLs.

Base URL: https://api.vidsynth.app/v1
02 // AUTHENTICATION PRIVATE BETA — ACCESS REQUIRED

Bearer Token Authentication

Approved partners authenticate requests using a workspace-scoped Bearer token in the Authorization header. Never embed secret API keys in client-side code.

Authorization: Bearer vs_live_<YOUR_APPROVED_PARTNER_KEY>
03 // GENERATION ENDPOINTS

Core Synthesis Routes

POST /v1/generations

Submit a character transformation or prompt-driven synthesis job with optional reference image conditioning.

GET /v1/generations/{id}

Poll generation status (queued, processing, completed, failed) and retrieve signed output URLs.

POST /v1/assets/reference

Upload a reference plate (JPG, PNG, WebP) to receive an isolated conditioning asset URI.

04 // REQUEST EXAMPLE cURL / HTTP JSON 
curl -X POST "https://api.vidsynth.app/v1/generations" \
  -H "Authorization: Bearer vs_live_partner_token" \
  -H "Content-Type: application/json" \
  -H "X-VidSynth-Request-Id: req_94f8a21c" \
  -d '{
    "prompt": "Stylized anime character transformation mid-choreography under warm twilight lanterns",
    "description": "Preserve primary subject pose and hand gesture; soft cel-shaded rim lighting",
    "stylePreset": "Anime Character Transformation",
    "aspectRatio": "9:16",
    "processingMode": "VS-CHAR-2.4"
  }'
